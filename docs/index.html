国際通り駐車場ガイド

車で行くなら、停める場所を先に決める。エリア別の傾向と、日曜の通行止め、停める前に確認すること。

近い順に駐車場を探す Punilo(プニロ)で地図から探せます。登録や料金はかかりません。

先に知っておく3つ

  1. 日曜の12時〜18時は、国際通りの本線に車で入れない。 県庁北口交差点から蔡温橋交差点までが「トランジットモール」として車両通行止めになります。雨天時は中止されることがあります。国際通りに面した駐車場は、この時間帯に出入りできないことがあります。 出典: 内閣府 国家戦略特区 沖縄県資料(2015年)。最終確認 2026-10-22。最新の実施状況は那覇市の案内で確認してください。
  2. 周辺は一方通行と細い路地が多い。 通り過ぎると一周して戻るのに時間がかかります。目的地に近い駐車場を1つ決め、そこに着くまでの入口の向きを地図で見ておくと迷いにくくなります。
  3. 料金はネットより看板が正しい。 料金は駐車場ごとに違い、看板の内容もよく変わります。このサイトは出典を示せない料金を載せません。停める前に現地の看板で3点を確認してください。
    • 時間あたりの料金(平日と土日祝で違うことがある)
    • 最大料金があるか
    • 最大料金が効く時間帯(「入庫後12時間」「当日24時まで」などの違い)

エリア別の傾向

国際通りは西の県庁側から東のゆいレール牧志駅まで約1.6km。目的地に合わせてエリアを選びます。

久茂地(西側・県庁前)

向いている人: 県庁・パレットくもじ・ゆいレール県庁前駅が目的地の人。

国際通りの入口側。オフィス街なので平日昼は空きが読みにくく、夜は比較的動きが出ます。久茂地川沿いの通りから入ると本線の混雑を避けやすいです。

松尾(中央・市場周辺)

向いている人: 第一牧志公設市場・市場本通り・むつみ橋あたりが目的地の人。

国際通りの真ん中。観光の中心で、土日祝と夕方は最も混みます。本線沿いに固執せず、一本南側(市場側)か北側の裏通りで探すと見つかりやすいです。

牧志(東側・牧志駅前)

向いている人: ゆいレール牧志駅・さいおんスクエア・安里方面が目的地の人。

国際通りの東の端。駅前に立体駐車場があり、本線の西側まで歩くより、ここに停めて通りを西へ歩く人も多いです。

少し離れて停める(安里・おもろまち・旭橋)

向いている人: 長時間いる人、日曜の午後に行く人、混雑を避けたい人。

ゆいレールの隣駅周辺に停めて1〜2駅乗る方法です。日曜のトランジットモール中はこの方法が確実です。

よくある質問

日曜日に国際通りへ車で行けますか?

本線(県庁北口交差点〜蔡温橋交差点)は毎週日曜の12時〜18時、トランジットモールとして車両通行止めです(雨天時は中止あり)。この時間帯は一本裏の通りか周辺エリアに停めるか、時間をずらすのが安全です。最新の実施状況は那覇市の案内で確認してください。

国際通り周辺の駐車場はいくらくらいですか?

駐車場ごとに大きく違い、看板もよく変わるため、このサイトでは出典を示せない料金を載せません。現地の看板で「時間あたり」「最大料金の有無」「最大料金が効く時間帯」を確認してください。

国際通りのどこに停めるのが楽ですか?

県庁側なら久茂地、市場なら松尾、牧志駅側なら牧志が近いです。本線は混みやすく一方通行も多いので、少し離れて歩くか、ゆいレールで移動するのも手です。

国際通り周辺のお店の方へ

駐車した直後の人は、これから歩いて店を探す人です。Punilo では、近くに停めた人のスマホにお店のクーポンを届けられます。チラシと違って、来られる距離にいる人にだけ届きます。
